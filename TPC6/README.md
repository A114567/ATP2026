- **Resumo:** No 6º trabalho de casa, foi-nos pedida a criação de uma aplicação em Python com um menu para análise de uma tabela meteriológica, na qual são guardados os registos de temperatura máxima, temperatura mínima e de ocorrências ao longo de vários dias. A variável que guarda estes registos é a tabMeteo, uma lista de tuplos, cada um correspondendo a um dia, com a estrutura: [(data,t_min,t_max,prec)]. Um dado de cada dia corresponde a um tuplo de inteiros, sendo data = (ano,mes,dia). 
Esta aplicação permite calcular as temperaturas médias, amplitudes térmicas e valores extremos, comparar valores com limites e desenhar gráficos impostos. Permite também salvar uma tabela num arquivo de texto e recuperá-la.
